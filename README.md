# Victoria's Travel Library

A bilingual, editorial-style index for Victoria's travel handbook websites.

## Included Sites

- Tokyo winter journal
- USA West Coast road trip
- Sendai and Aomori winter trip
- Tokyo shopping trip
- Seoul travel handbook
- Australia travel handbook
- Bali and Java travel handbook
- AIB Manchester and UK trip

## Structure

- `index.html`: semantic page content, travel links, and SEO metadata
- `styles.css`: typography, editorial visual system, and responsive layout
- `script.js`: lightweight Chinese/English language switching
- `favicon.svg`: browser icon
- `og-card.png`: social sharing image
- `robots.txt` and `sitemap.xml`: search engine discovery files

## Deploy

The project has no build step or runtime dependencies. All asset paths are relative, so it can be published directly from the repository root on GitHub Pages.
