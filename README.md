# Victoria Travel Collection

An elegant landing page that curates Victoria's travel websites in one place.

## Included Sites

- Tokyo shopping trip
- Bali x Java travel handbook
- USA West Coast trip
- Tokyo winter itinerary
- Sendai and Aomori travel site

## Structure

- `index.html`: page structure
- `styles.css`: visual system and responsive layout
- `script.js`: travel site data and card rendering

## Deploy

This project is ready for GitHub Pages as a static site.
